# Contributing to Intelligent Network Analyzer

Thank you for your interest in contributing!

## Code of Conduct
Please review our [Code of Conduct](CODE_OF_CONDUCT.md) before participating.

## Getting Started
1.  Fork the repository.
2.  Clone your fork: `git clone https://github.com/YOUR_USERNAME/intelligent-network-analyzer.git`
3.  Install dependencies:
    - Backend: `pip install -r network-monitor/requirements.txt`
    - Frontend: `cd network-monitor/frontend && npm install`

## Workflow
1.  Create a feature branch: `git checkout -b feature/amazing-feature`
2.  Commit your changes: `git commit -m 'Add amazing feature'`
3.  Push to the branch: `git push origin feature/amazing-feature`
4.  Open a Pull Request.

## Coding Standards
- **Python**: Follow PEP 8. Run `flake8` to lint.
- **JavaScript**: Use ES6+ features.
- **Tests**: Ensure all new features have accompanying tests.

## Reporting Bugs
Use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md) to submit issues.
